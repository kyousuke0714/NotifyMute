# NotifyMute
NotifyMute 1.5.1
批量管理微信 / QQ 的消息免打扰 —— 让手机在夜里安静，但急事仍能叫醒你。

不 root、不刷机、不装 Xposed，只用系统的「通知使用权」。

⚠️ 安装前必读
这个应用装完是不能直接用的，必须先授予权限，否则它看起来就像个没反应的空壳。

首次打开会自动进入 4 步向导，跟着走完：

通知使用权 —— 唯一必需的系统权限
电池优化白名单 —— 防止系统为省电杀掉监听服务
允许自启动 —— 国产手机会拦截第三方自启，必须手动开
响铃自检 —— 验证「取消通知」能否赶在响铃之前完成
vivo / iQOO 等机型每次安装都会弹确认框，必须手动点「继续安装」。

这个版本有什么
关键词唤醒（核心功能）
被静音的人，如果消息里含有你设的关键词：

立刻响（这条放行）
之后他发的每条都会响，直到安静 60 分钟为止
静音一个人本质上是在赌——赌他不会说重要的事。有了这个就可以放心静音：万一真有急事，对方提一句就能把你叫醒。

误报时，通知栏会出现一条提示，点「静音回去」即可一键撤销。

⚠️ 不要对想让关键词唤醒的人使用微信自带的「消息免打扰」—— 微信自己关掉提醒后，本应用无法让它响。微信里保持正常，静音操作在本应用里做。

名单规则：提前静音还没联系过的人
微信不提供任何"列出联系人"的接口，同类工具只能被动发现给你发过消息的人。 名单规则补上这个缺口：主动输入名字，规则不依赖会话是否存在。

支持批量导入，导入前会跑试匹配预检，标出「未出现」（可能打错）与「会互相覆盖」的名字。

临时静音
全局或单人，档位可自定义（默认 30分 / 1时 / 2时 / 到明早8点）。 「到明早 8 点」是到点式：不管现在几点，都到次日早上 8 点为止。

定时免打扰
设定时段自动生效，支持跨午夜（23:00 → 08:00）。

界面
底部 5 个标签：名单 / 定时 / 记录 / 关键词 / 设置。 首次使用有向导引导。

措施	说明

不保存消息内容	只存「谁、何时、被如何处理」

已知限制
限制	说明
不管群聊	交给微信自带的「@我时提醒」
不能改微信内部的免打扰开关	Android 不允许第三方应用改别的应用内部设置
微信里仍有未读小红点	拦的是通知，不是消息本身
被「强行停止」后无法自动恢复	Android 不允许应用自己重启
重启后需解锁一次屏幕	系统启动广播要等首次解锁后才发出
名字打错会静默失效	纯文本匹配的固有限制，靠「试匹配预检」缓解
